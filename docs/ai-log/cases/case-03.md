# case-03 — 조건 중심으로 AI 후보 8개를 받고, 빵집 후보를 변형해 "모찌 메이커"로 컨셉 확정

단계/태스크: 1단계 기획 / P01 · 일시: 11-18 · 판정: (사용자 기입: 채택 / 수정 / 기각)

## 1. 문제 — 상황과 제약
- 5일(11/17~11/21) 1인 UE 5.5 Android 프로젝트. 모바일은 처음이고, Day 2(11/18) 시작 시점까지 컨셉 미정
- 필요한 것: 기간 안에 끝나고(Must 합계 20h 이내) 프로그래머 기술 포인트 3개 이상을 보여 줄 컨셉
- 키우기형 · 간단 시뮬레이션 아이디어는 있었지만, 후보 비교 없이 미리 정하지 않음

## 2. 프롬프트 변화 — v0 → 점검 → v1 (docs/ai-log/prompts/planning.md)
- v0: 가중치 기준 6개로 채점, 5점 이하 제외, 후보 5개 이상을 오름차순으로
- 점검(/prompt-check)에서 잡은 것
  - 채점 척도 미정: 0/1이면 동점이 많고, 1~5면 최저점이 11점이라 컷이 아무것도 거르지 못함
  - 구현 가능성이 가점 항목이라 20h를 넘는 후보도 컷 통과 가능
  - 일정과 Must 시간의 관계 모호, 지침의 1단계 완료 기준 누락, 탈락 후보 기록 누락, 성능 기준 막연
- 2차 질문: 만점 계산 불일치(지정 25점, 실제 24점), 컷 경계(15점 통과 여부)
- v1: 필수 조건 4개(게이트) + A~E 평가표(만점 24점, 16점 이상 통과), 시간복잡도 항목, 키우기·시뮬레이션 후보 필수 포함, 항목별 근거와 Must 시간 출력, 최종 추천 금지
- 점검 의견 13건 중 12건 반영(일부는 사용자가 고쳐서 반영), 1건 미반영

## 3. AI 결과 요약 (원본: Claude 채팅 기록 — 링크 기입)
- 후보 8개 중 통과 4개: 대장간 키우기 24 · 포션 머지 23 · 골목 빵집 운영 22 · 슬라임 펫 키우기 22
- 탈락 4개: 매치-3 · 타워 디펜스 · 덱빌더(필수 조건 1 위반) / 리듬 탭(13점)
- 통과 4개는 A · D · E 점수가 같아서 순위는 B(모바일 적합성) · C(이미지 의존도)에서만 갈림
- 채점표 전체: docs/01_planning/concept-selection.md
- 이후 흐름
  1. 사용자: 빵집 후보를 과일모찌 가게로 변형 제안
  2. AI: 기간 내 가능 여부 점검, GDD 초안 작성(GDD_draft.md)
  3. 사용자: 세부 설계 추가
  4. AI: 충돌 6건 정리, 질문 3건
  5. GDD v1
  6. 사용자: 혼합 판매가 배수 · 버리기 버튼 추가 → GDD v1.1
  7. 사용자: "골드가 모자란 재료 비활성" 규칙의 빈틈 발견 → 빚 · 파산 규칙으로 교체 → AI 검토 → GDD v1.2

## 4. 판별 — 무엇을 근거로 받아들이고 / 고치고 / 버렸나
- 검증 방법
  - 최종 컨셉을 고를 때는 플레이어 입장에서 게임으로서의 가치(재미)를 따졌다.
  - 빈틈을 찾기 위해, 이 게임을 실제로 구현했을 때의 플레이 흐름을 처음부터 끝까지 따라가 봤다.
- 발견한 문제와 근거
  - 게임 흐름을 따라가다가, AI가 제시한 규칙 "소지금보다 비싼 재료는 비활성화"에 문제를 발견했다.
  - 게임 규칙에는 "잘못된 방식으로 만들면 쓰레기로 자동 폐기"와 "재료 선택한 순간 재료비 차감"이 함께 있다. 쓰레기를 연속으로 만들면 소지금이 일정 수치 아래로 떨어져 어떤 재료도 고를 수 없게 되고, 할 수 있는 작업이 아무것도 없다.
- 수정
  - "소지금보다 비싼 재료는 비활성화" 규칙을 삭제하고, 소지금이 마이너스(빚)로 내려가는 것을 허용했다.
  - 빚이 생기면 화면 상단에 "파산위기!" 표지판을 띄운다. 빚인 채로 하루를 마치고 다음 날 영업이 끝날 때도 빚을 갚지 못하면 파산(게임 오버)이다. 게임 오버 후에는 메인 화면(로비)으로 돌아가 처음부터 다시 시작한다.
  - 작업 중인 제품 버리기 버튼은 편의 기능이 부족하여 추가했다.

## 5. 최종 반영 (커밋 해시)
- 산출물: docs/ai-log/prompts/planning.md · docs/01_planning/concept-selection.md · docs/01_planning/GDD_draft.md · docs/01_planning/GDD.md(v1.2)
- 커밋: (해시 · 태그 기입)
- AI 점검이 문제를 잡고, 사용자가 선택지 중에서 결정한 것
  - 채점: 게이트 도입, 0~3점 척도, 만점 24점 · 16점 이상 통과
  - 골드가 바닥나 진행이 멈추는 문제 → 최소 자금 보장 (이후 빚 · 파산 규칙으로 대체, 4번 참고)
  - Must 23h 초과 → Must는 단순 연출, 단계별 세부 모션은 Could
  - 작업대 추가 업그레이드가 무의미해짐 → 찜기 업그레이드
- 사용자가 직접 추가한 설계
  - 베이스 3종(팥 · 요거트 · 두바이초코) + 과일 4종, 순차 해금(딸기 → 블루베리 → 요거트 → 파인애플 → 망고 → 두바이초코)
  - 재료비, "아무거나" 주문, 찜기 게이지
  - 베이스 → 과일 → 떡 3클릭 조립, 쓰레기 판정, 연출 중 입력 잠금
  - 영업 화면 레이아웃(재료통 배치 포함), 혼합 판매가 배수(잠정 1.25), 버리기 버튼
  - 빚 허용, "파산위기!" 표지판, 빚 상태로 이틀 연속 마감 시 게임 오버 → 처음부터 재시작
