git diff의 변경사항을 CLAUDE.md 규칙과 아래 체크리스트로 리뷰해줘. 코드는 고치지 말고 지적만 해.
- UPROPERTY 없는 UObject 포인터 멤버
- 불필요한 Tick, 매 프레임 메모리 할당
- UE 5.5에 없는 API나 시그니처가 의심되는 호출
- 범위 밖 파일 수정, 불필요하게 늘어난 함수·변수
- 모바일: 백그라운드/복귀, 해상도, 저장 실패 처리 누락
형식: [높음/중간/낮음] 파일:줄 — 문제 — 근거 — 제안
