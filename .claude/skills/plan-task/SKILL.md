docs/03_impl/tasks.md에서 태스크 $ARGUMENTS 를 찾아 아래 형식으로 계획만 제시해줘. 파일은 수정하지 마.
1. 완료 조건 (tasks.md 그대로 인용)
2. 수정할 파일 / 새로 만들 파일
3. 새 클래스·함수·변수 목록과 각각의 필요 이유 (기존 코드 확장으로 대체 가능한지 검토 결과 포함)
4. 사용할 엔진 API와 확신도 (확실 / 확인 필요)
5. 검증 방법 (컴파일, PIE 시나리오, 실기기 확인 항목)
6. 사람이 에디터에서 해야 할 작업 (BP · UMG · 에셋)
